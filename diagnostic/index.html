Cómo configurar tu proyecto de Firebase
  1. Crea un proyecto en console.firebase.google.com y añade una app web para obtener el bloque JSON de configuración.
  2. En Authentication, activa el método «Correo electrónico/contraseña».
  3. En Firestore Database, crea la base de datos y pega estas reglas de seguridad:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /printcost/{uid} {
      allow read, write: if request.auth != null
                         && request.auth.uid == uid;
    }
  }
}

Pega el JSON en este panel, pulsa «Guardar y Conectar Firebase» e inicia sesión.
